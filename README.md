# Lật mảnh ghép — công cụ giáo viên

- Tải ảnh bí mật trực tiếp từ máy.
- Tải bộ câu hỏi .xlsx/.xls/.csv.
- Chọn 3×3, 4×4, 5×5 hoặc 6×6.
- Chọn 3/5/7/10 phút.
- Đúng mở mảnh; sai khóa mảnh.
- Mỗi câu chỉ trả lời một lần, không quay lại.
- Không cần máy chủ; ảnh và câu hỏi chỉ xử lý trong trình duyệt.

Mẫu dữ liệu: Câu hỏi | A | B | C | D | Đáp án (A/B/C/D).

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
